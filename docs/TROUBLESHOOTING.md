# 動かない場合

| 状況 | 確認すること |
|---|---|
| 画面が開かない | `初期設定.cmd` の結果。Python 3.11以降と.NET Frameworkコンパイラがあるか |
| 投稿先が選べない | 「アプリ設定」でルーム名全文を登録して保存したか |
| 予約が動かない | 投稿タスクの登録、予約投稿の一時停止、08:00〜21:00の時間枠、LINEログイン、ロック解除 |
| 取得されない | 取得タスク、全体とルームの有効設定、日次開始時刻、PCが操作可能か |
| ダウンロードに失敗 | LINEの既知の失敗表示と安全な閉じ処理を確認できれば画面取得へ切り替える。それ以外の失敗は「取得状況」の原因を確認 |
| 画面取得が途中 | 保存した本文と位置を使い、上限内で継続。要確認になった場合はスマホの履歴取込などで補完 |
| 要確認の投稿 | LINE上の対象ルームを見て確認。「確認終了」は記録を閉じるだけで再送しない |
| 本文は届いたが画像が不明 | 2通のうち片方だけ成功した可能性。投稿履歴の内訳を確認し、自動で全文を送り直さない |
| 再開したら大量投稿しそう | 投稿を一時停止したまま予約一覧と繰り返し予約を確認。不要な予約を取り消してから再開 |

LINEの画面更新、表示倍率、ダイアログ、他のアプリによる操作競合で停止する場合があります。ウイルス対策やPCの保護機能を無効にして解決しようとしないでください。

不具合を共有するときは、エラー名・操作手順・WindowsとLINEのバージョンを記載してください。`state/` 全体、本文、参加者名、ブラウザセッショントークン、認証情報をIssueへ貼り付けないでください。必要な画像は個人情報を伏せてください。
