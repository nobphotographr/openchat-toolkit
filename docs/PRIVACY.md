# データとプライバシー

このリポジトリにはソースコード、説明書、合成テスト、空の設定例、操作ラベル画像とアプリアイコンを含みます。元の利用者の宛先・履歴・投稿本文・画像・予約・認証情報は含みません。

## 初期設定

- 宛先は未登録です。利用者が「アプリ設定」でルーム名全文を登録します。
- 自動取得は無効、予約投稿は一時停止です。
- 取得時刻03:00、日本時間、投稿可能時間08:00〜21:00は共通の初期動作として明示した値です。個人の予約を引き継いだものではありません。
- LINE実行ファイルの場所はWindowsのユーザーフォルダーから動的に取得します。個人のWindowsユーザー名を固定していません。
- ブラウザ用トークンは起動時にランダム生成します。固定トークンや外部APIキーは配布しません。

## 利用後に公開してはいけないもの

`collector-config.json`、`state/`、トーク履歴ファイル、スクリーンショット、投稿用画像、ログ、ブラウザプロファイル、認証情報は利用者のデータです。プライベートリポジトリにも追加しないでください。

ソースを共有するときは、`release-files.json` の一覧に含めるファイルを確認し、`python audit_release.py` を実行してください。新しいソース内に個人情報を書き込んだ場合も対象になるので、一覧と `.gitignore` だけで漏えいが完全に防げるわけではありません。

コミットの作成者名・メールアドレスも共有相手に見えます。個人用のメールを出したくない場合は、GitHubのnoreplyアドレスなどを利用してください。過去の実行データを含むGit履歴をそのまま共有しないでください。

## 外部との接続

履歴保存・検索・予約管理はローカルで動作します。LINEへの実投稿はLINEアプリを通じて行います。ブラウザ画面はループバックの `127.0.0.1` だけを使用します。AIへの履歴送信、Slack/GAS連携、アクセス解析、独自サーバーへのデータ送信は組み込んでいません。

Windows側のデータは暗号化DBではありません。必要に応じてPCのアクセス権やバックアップ先を管理してください。
